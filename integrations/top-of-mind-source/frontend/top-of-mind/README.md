# Top of Mind Frontend

React/Vite MVP for the local Top of Mind multi-AI command desk.

## Run

```bash
npm install
npm run dev
```

The app expects the API at `http://127.0.0.1:8000` by default. Override with:

```bash
VITE_TOP_OF_MIND_API=http://127.0.0.1:8000 npm run dev
```

## Build

```bash
npm run build
```
